# Data and licensing boundary

The repository contains only small, self-authored fixtures. It does not redistribute complete HS, SITC, BEC, NAICS, or NACE tables.

When adding a real concordance, record the issuing organization, edition/year, retrieval URL, transformation date, and redistribution permission in a separate data package. Keep raw official files out of this code repository unless their license explicitly permits redistribution. The algorithms in `src/` are original project code and are not a claim of ownership over any classification standard.
