# MoonBit 国际贸易商品分类映射与版本转换库

项目标识：`moonbit-tradeclass`

本项目面向国际贸易统计、海关分析和经济研究，解决不同数据源之间商品分类口径不一致、年份不可比、映射过程不可追溯的问题。核心对象包括分类体系、版本、商品代码、concordance 规则、映射置信度和聚合计划；支持多级目录、代码失效、拆分、合并、一对多及带权映射，并输出精确、近似、不可映射三种结果及原因。首期只实现通用规则格式、版本转换和聚合算法，不捆绑受版权约束的完整官方数据库，避免把算法和数据许可混在一起。

首个可交付版本将以 MoonBit 0.10.3 为基线，提供可复用库、少量自制夹具、可运行测试和 CI。测试覆盖代码新增、删除、拆分、合并、循环映射、缺失映射、权重和按国家/年份聚合；README、NOTICE 与数据来源说明明确区分官方分类原始数据和本项目代码。后续可扩展 JSON/CSV 导入导出、版本差异报告、自动迁移、映射质量评估、用户自定义行业分类、贸易指标计算及 WASM 组件，并拆分为多个 Mooncakes 子包。

选择 MoonBit 是因为该项目需要一个小而清晰的纯数据模型、确定性的文本处理和可移植的后端；库接口可以从本地工具延伸到 WASM 数据分析场景。Mooncakes 关键词检索未发现 concordance、HS code、SITC、BEC、NAICS、NACE 或贸易分类映射项目；已有 DataFrame/OLAP 包属于可选底层能力，功能边界不同。

开发将保持公开、可复现：默认分支、有效提交历史、许可证、生成接口文件和 GitHub Actions 均纳入验收；CI 按 MoonBit 0.10.3 实际接口执行 `moon fmt --check`、`moon info` 后的差异检查、`moon check --deny-warn`、普通/native 测试及 CLI 检查。项目只由仓库创建者账号提交，不生成虚拟贡献者或虚构来源。
